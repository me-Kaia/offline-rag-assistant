# SOP-PM-003 深硅刻蚀设备月度保养规范
（演示用模拟数据，设备与参数为虚构）

版本：A　生效日期：2025-11-01　归口部门：设备工程部
适用设备：ETCH-02、ETCH-03
保养周期：每月一次，或累计 RF 时数达 80 小时（先到为准）
预计停机时间：6 小时

## 1. 保养项目
| 序号 | 项目 | 是否停机 | 标准 |
| --- | --- | --- | --- |
| 1 | 腔体湿法清洗（去除腔壁聚合物） | 是 | 目视无残留，颗粒测试合格 |
| 2 | 更换上电极石英窗口 O 形圈 | 是 | 无老化、龟裂 |
| 3 | 检查静电吸盘（ESC）氦背冷漏率 | 是 | ≤ 2 sccm |
| 4 | RF 匹配器反射功率检查 | 否 | 反射功率 < 2% |
| 5 | 干泵运行电流与温度记录 | 否 | 与基线偏差 < 10% |
| 6 | 气体管路保压测试 | 是 | 30 分钟压降 < 1% |
| 7 | 机械手传片校准 | 是 | 偏移 < 0.2 mm |

## 2. 保养后恢复
1. 腔体抽真空并进行 2 小时 Seasoning（陈化）。
2. 跑颗粒测试片和刻蚀速率监控片，均合格后方可放行。
3. 在设备履历系统中登记保养记录，清零 RF 时数计数器。

## 3. 安全
- 开腔前执行 LOTO（上锁挂牌），确认气体已吹扫。
- 湿法清洗使用 IPA 与去离子水，禁止使用含氯溶剂。
